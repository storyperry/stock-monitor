# 桌面股票监控小工具（Windows）

常驻桌面的极简 A 股行情小窗：无边框、真透明、字体清晰、可一键隐藏，适合上班时低调查看。
数据来自腾讯行情接口，默认 3 秒刷新。

> 当前可用版本：**`app_v20.py` + `启动股票监控_v20.bat`**（v1~v19 作为迭代记录保留在仓库里）。

## 功能

- 实时行情：现价、涨跌幅、量比、成交量、最高价、最低价
- 涨红 / 跌绿自动着色，颜色可自定义
- **真·无背景**：背景 alpha=0 完全透明，只留文字（见下方"渲染原理"）
- 全局快捷键隐藏/显示（默认 `Ctrl+Alt+H`，可改，支持录制）
- 双击一行弹分时图（含均价线、昨收基准线），支持日/周/月/分钟 K 线周期切换
- 窗口任意位置左键按住即可拖动，拖到哪固定在哪
- 鼠标中键/滚轮隐藏，鼠标离开自动隐藏（上班族模式）
- 隐藏到系统托盘，托盘图标可自定义
- 界面透明度、背景色、字体颜色/大小/透明度、行高、显示列全部可在设置里改

## 安装与运行

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
启动股票监控_v20.bat
```

需要 Python 3.10+（自带 tkinter）。VMware/无管理员权限环境下快捷键可能失效，届时"以管理员身份运行"。

## 使用方法

- 添加股票：右键 → 添加股票。`600519`、`000001`、`300xxx`、`159xxx`、`510xxx` 会自动补 `sh`/`sz` 前缀；指数请写全（`sh000001`、`sz399001`）
- 删除股票：选中一行 → 右键 → 删除选中
- 设置：右键 → 设置…（或标题栏 ⚙）
- 退出：右键 → 退出，或托盘右键 → 退出

## 配置

运行后自动生成 `config.json`。仓库只提供 `config.example.json`，复制为 `config.json` 即可：

| 关键项 | 说明 |
| --- | --- |
| `bg_mode` | `px`=真·无背景（每像素透明，推荐）/ `translucent`=半透明底 / `solid`=不透明 |
| `px_outline` | 文字描边：0 无（最纤细）/ 1 极细 / 2 细 / 3 粗。浅色或纯色背景上调到 2 更清楚 |
| `font_alpha` | 字体不透明度（0-100）。调到 30 左右会明显发虚 |
| `window_alpha` | 标题栏/窗口整体透明度 |
| `auto_hide` | 鼠标离开多少秒后自动隐藏，0=关闭 |

## 渲染原理（这一版的核心）

tkinter 不支持每像素 alpha，所以文字层走 Win32：

1. Pillow 用 FreeType **3 倍超采样**画字（灰度抗锯齿，天然没有 ClearType 的彩色毛边）
2. **预乘 alpha** → LANCZOS 缩小 → **强制 `rgb ≤ alpha`**
3. `UpdateLayeredWindow` + `ULW_ALPHA` 贴到 `WS_EX_LAYERED` 窗口上

两个踩过的坑，改动这段代码时注意：

- **缩放后必须 clamp**。LANCZOS 有负瓣振铃，会留下 `rgb > alpha` 的像素（如 `(255,255,255,1)`），Windows 按 `out = rgb + bg*(1-a)` 合成，这些像素变成"颜色叠加"——在纯蓝/纯色背景上表现为青/粉毛边、白点、笔画断线。
- **不要再用颜色键（`-transparentcolor`）**。ClearType 的亚像素边缘像素抠不干净，必然出现重影和缺口。

另外：背景完全透明后鼠标会穿透，所以叠了一层 alpha=0.004 的"幽灵点击层"，让整窗矩形内任意位置都能点击和拖动。

## 版本记录（节选）

- **v20**：修"真·无背景"被设置对话框打回颜色键模式；3x 超采样 + clamp（修蓝底彩边/断线）；文字描边四档；ETF 长名自动压缩（`沪深300ETF华泰柏瑞` → `沪深300ETF`）

- **v17**：单实例守卫，避免两个透明窗叠加重影
- **v15**：分时图左右双轴（价格 / 涨跌幅）
- **v13**：修分时图无数据（`web.ifzq.gtimg.cn` 被 WAF 拦截，改用 `ifzq.gtimg.cn`）
